# Food Delivery Business Intelligence & Operational Performance Analytics

## Project Overview
An end-to-end food delivery analytics project focused on evaluating restaurant performance, order trends, revenue contribution, food categories, customer ratings and geographic performance.

## Technologies Used
- Microsoft Fabric
- Microsoft SQL Server (T-SQL)
- Power BI

## Project Components
1. Data ingestion and preparation using Microsoft Fabric.
2. SQL-based data exploration and data quality validation.
3. Business analysis using SQL queries and window functions.
4. Interactive Power BI dashboard development.
5. Business insights and performance analysis.

## Key Business Metrics
- Total Orders: 197,430
- Total Restaurants: 993
- Total Revenue: ₹53.01 Million
- Average Order Value: ₹268.51
- Average Rating: 4.34

## Key Analytical Areas
- Monthly revenue trends and growth
- Restaurant performance rankings
- Food and category analysis
- City and state performance
- Restaurant ratings and price segmentation
- Revenue stability and Pareto analysis

To transform food delivery data into meaningful business insights and support data-driven decision-making.
